## Usage Guidelines
- All images are displayed with full contrast overlays (`rgba(10, 37, 64, 0.78)`) ensuring accessibility (WCAG 2.1 AAA).
- Meaningful semantic `alt` attributes in both English and Hindi are attached via the `CivicImage` component.
- Used strictly for demonstrating the **Problem Statement CHA-195** crowdsourced civic redressal lifecycle (Problem -> Report -> Inspection -> Action -> Resolution).
